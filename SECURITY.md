# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/AlvaroMunozS/AniHub/security/advisories/new).
Do not open a public issue.

Include the affected version, the steps to reproduce and the impact you expect.

## Scope

- The AniHub app and the data it stores on the device.
- The release pipeline and the signed APKs published in
  [Releases](https://github.com/AlvaroMunozS/AniHub/releases).

Only the latest release receives fixes.

Issues in MyAnimeList or its API belong to
[MyAnimeList](https://myanimelist.net).
